# World boundaries

`world.json` is derived from Natural Earth 1:110m Admin 0 countries, v5.1.2.
Source: https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_admin_0_countries.geojson
License: public domain — https://www.naturalearthdata.com/about/terms-of-use/

Geometry is unchanged. Unused properties are removed, ADMIN becomes name,
United States of America is renamed United States and Republic of Serbia becomes Serbia to match Random User,
and Antarctica is omitted for a more readable world view.
These generalized boundaries are for a small-scale visualization, not street maps.
